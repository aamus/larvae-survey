# Larvae Survey

A mobile-friendly, offline-capable PWA for mosquito larvae field inspections. It supports survey sessions, house photos, GPS capture, saved field staff directories, and PDF report generation with Bangla text.

## Live app

https://aamus.github.io/larvae-survey/

## Technology

This is a static HTML/CSS/JavaScript app. Its PDF libraries and Bangla font are bundled locally, and a service worker caches the app for offline use after the first successful load.

## Privacy

Survey records and saved setup information remain in the user's browser/device storage. This repository contains no Android signing key or private credentials.
